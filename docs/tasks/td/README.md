# Technical Debt Detail Guide

이 폴더는 [Remaining Tasks](../../remaining_tasks.md)의 TD 항목에 연결되는 상세 기술 명세를 관리한다.
`remaining_tasks.md`에는 상태, 우선순위, 요약과 검증 가능한 완료 조건만 유지한다.

상세 문서는 다음 항목을 필요에 따라 사용한다.

- 배경 및 현재 구조
- 문제와 위험
- 관련 위치
- 목표 구조 및 구현 범위
- 범위 제외와 기술 제약
- 검증 계획
- 완료 증거

구현 중 발견한 세부사항은 해당 TD 문서에 기록한다. 여러 작업에 지속적으로 적용될 결정은
[Design Decisions](../../decisions.md), 구현 완료 후의 현재 구조는 architecture/API 문서,
실제 완료 결과는 [Work Log](../../worklog.md)에 반영한다.
